# Kristin Chen — AI Portfolio

Personal portfolio for Kristin Chen, focused on practical AI workflows, AI enablement, and data-informed decision-making.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn-style UI primitives

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build -- --webpack
```
